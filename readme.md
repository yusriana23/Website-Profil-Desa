# 🌿 Website Profil Desa Harmoni

Website Profil Desa Harmoni merupakan proyek Ujian Akhir Semester (UAS) mata kuliah **Perancangan Web**. Website ini dibuat sebagai media informasi digital yang menampilkan profil desa, layanan administrasi, galeri kegiatan, berita, dan informasi kontak sehingga masyarakat dapat memperoleh informasi desa secara mudah dan cepat.

# 📄 Deskripsi Halaman

## 1. Beranda (index.html)

Berisi informasi singkat mengenai Desa Harmoni, statistik desa, potensi desa, dan berita terbaru.

Fitur:

- Hero Banner
- Statistik Desa
- Potensi Desa
- Berita Terbaru
- Responsive Layout

---

## 2. Profil (profil.html)

Berisi informasi lengkap mengenai desa.

Meliputi:

- Sejarah Desa
- Visi
- Misi
- Data Umum Desa
- Struktur Organisasi

---

## 3. Layanan (layanan.html)

# 💻 Cara Menjalankan Website

### Menggunakan Visual Studio Code

1. Download atau Clone repository

```
git clone https://github.com/username/Website-Profil-Desa.git
```

2. Buka folder project menggunakan Visual Studio Code.

3. Install extension **Live Server**.

4. Klik kanan pada file

```
index.html
```

5. Pilih

```
Open with Live Server
```

Website akan terbuka pada browser.
